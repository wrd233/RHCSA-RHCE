外部数据、敏感变量与 Vault - Anki 预览

正面

创建/编辑/查看 Vault 文件分别用什么？

背面

ansible-vault create/edit/view

正面

轮换 Vault 密码且保持加密用什么？

背面

ansible-vault rekey

正面

加密单个值用什么？

背面

ansible-vault encrypt_string

正面

Vault 文件头典型是什么？

背面

$ANSIBLE_VAULT;...

正面

Vault 是否自动隐藏运行时输出？

背面

不会。

敏感 task 需 no_log。

正面

no_log 应放在哪里？

背面

最小的敏感 task/block。

过宽会阻碍诊断。

正面

user.password 应传明文吗？

背面

不应；通常传目标系统支持的密码哈希。

正面

vars_files 与 group_vars 区别？

背面

前者 play 显式加载；后者按 Inventory 自动加载。

正面

批量数据执行前如何验证 schema？

背面

用 assert 检查必需键和类型。

正面

为什么不先 decrypt 再编辑？

背面

会在磁盘留下明文并扩大泄露窗口。

使用 vault edit。

正面

Vault 验收层？

背面

文件仍加密、授权可 view、Playbook 解密运行、日志无秘密、远端终态正确。

正面

no vault secrets found 查什么？

背面

vault-id/password file、文件头与 ID 匹配。

正面

轮换 Vault 密码并保持密文使用 ansible-vault […]。

背面

轮换 Vault 密码并保持密文使用 ansible-vault rekey。

不要 decrypt 编辑。

正面

Vault 保护[…]，敏感 task 输出用 […]。

背面

Vault 保护静态文件，敏感 task 输出用 no_log: true。

两层不同。
