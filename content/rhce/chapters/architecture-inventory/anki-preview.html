Ansible 架构、配置与 Inventory - Anki 预览

正面

查看 Ansible 当前使用的配置文件，最直接看什么？

背面

ansible --version 输出中的 config file。

再用 config dump 看有效差异。

正面

显示非默认有效配置的命令是什么？

背面

ansible-config dump --only-changed

用于发现配置漂移。

正面

以树形展示 Inventory 组关系用什么？

背面

ansible-inventory --graph

不能证明连接。

正面

展开某主机最终 Inventory 变量用什么？

背面

ansible-inventory --host <HOST>

观察 hostvars 合并。

正面

Inventory 名称与 ansible_host 的区别是什么？

背面

前者是逻辑 inventory_hostname，后者是连接地址。

模板中常需区分。

正面

children 组的 ini 标题骨架是什么？

背面

[parent:children]

下面列子组名。

正面

验证 pattern 实际匹配主机用什么？

背面

ansible <PATTERN> --list-hosts

在执行前使用。

正面

ansible.builtin.ping 证明什么？

背面

控制端能通过连接执行 Python 模块并返回 pong。

不证明 ICMP 或 become。

正面

验证 become 到 root 的最小 ad hoc 命令骨架是什么？

背面

ansible <PATTERN> -b -m ansible.builtin.command -a 'id -u'

预期输出 0。

正面

pattern 匹配 0 主机首先查什么？

背面

Inventory 路径、graph、组名和 --list-hosts。

不先查 SSH。

正面

UNREACHABLE 首先查哪一层？

背面

SSH 地址、用户、密钥、主机密钥和网络。

用 -vvv 与同身份 ssh。

正面

ping 成功但权限失败下一步是什么？

背面

检查 become 配置和远端 sudo 授权。

连接层已成立。

正面

为什么不把口令放入 ansible.cfg/Inventory？

背面

会明文泄露且扩大项目暴露面。

使用 Vault 或题目安全入口。

正面

RHCE 项目执行前的证据链是什么？

背面

配置来源 → Inventory 图/变量 → pattern → SSH/Python → become。

再进入业务模块。

正面

配置来源先看 ansible --version 的 […]；主机范围先看 […]。

背面

配置来源先看 ansible --version 的 config file；主机范围先看 --list-hosts。

执行边界。

正面

Inventory 的逻辑名是 […]，连接地址可由 […] 指定。

背面

Inventory 的逻辑名是 inventory_hostname，连接地址可由 ansible_host 指定。

名称与地址分开。
