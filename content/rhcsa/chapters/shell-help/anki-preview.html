正面

单引号与双引号对变量展开的区别是什么？

背面

单引号保留字面文本；双引号允许变量和命令替换。

双引号同时抑制分词和文件名展开。

正面

为什么路径变量通常写成 "$path"？

背面

防止空格分词和通配字符再次展开，保持一个参数。

未引用变量可能改变参数数量。

正面

捕获 date +%F 输出到变量 today 的推荐写法是什么？

背面

today=$(date +%F)

$(...) 比反引号更易嵌套和阅读。

正面

$? 保存什么？什么时候读取才有意义？

背面

上一条前台命令的退出状态；必须在其他命令覆盖它之前读取。

0 通常只表示该命令按自身定义成功。

正面

cmd1 && cmd2 与 cmd1 || cmd2 的执行条件是什么？

背面

&& 在前者成功时继续；|| 在前者失败时继续。

分号则无条件继续。

正面

stdout、stderr 对应的文件描述符是什么？

背面

stdout 是 1，stderr 是 2。

stdin 是 0。

正面

覆盖 stdout 与追加 stdout 分别使用什么？

背面

> 覆盖，>> 追加。

> 会在命令读取输入前截断目标文件。

正面

把 stderr 单独覆盖写入 /tmp/errors 的语法是什么？

背面

2> /tmp/errors

追加错误使用 2>>。

正面

把 stdout 与 stderr 都写入同一文件的典型顺序是什么？

背面

command >file 2>&1

先改变 stdout，再让 stderr 复制该目标。

正面

为什么 command 2>&1 >file 通常不会把两个通道都写入文件？

背面

stderr 先复制了当时的 stdout（终端），之后只有 stdout 改到文件。

重定向从左到右处理。

正面

管道 a | b 默认传递 a 的哪个通道？

背面

stdout。

stderr 默认仍指向原目标。

正面

在管道中同时保存数据并继续传给下一命令，使用什么工具？

背面

tee；追加写入使用 tee -a。

它从 stdin 读取并复制到文件和 stdout。

正面

Bash 中怎样查看管道各环节的退出状态？

背面

PIPESTATUS 数组。

默认 $? 只反映最后一个命令；脚本可考虑 pipefail。

正面

判断名称是 alias、内建、函数还是外部命令，首选什么？

背面

type <NAME>；查看全部入口可用 type -a <NAME>。

which 不能完整解释 Shell 语义。

正面

查看 Bash 内建 test 的帮助，使用什么命令？

背面

help test

外部命令通常使用 --help 和 man。

正面

man 5 crontab 中的 5 表示什么？

背面

手册的文件格式与约定章节。

man crontab 可能默认打开命令章节。

正面

不知道命令名，只知道功能描述时使用什么本地入口？

背面

apropos <KEYWORDS> 或 man -k <KEYWORDS>。

搜索依赖 man 数据库索引。

正面

反查哪个包提供 semanage 的命令是什么？

背面

dnf provides '*/semanage'

先排除拼写和 PATH 问题。

正面

dnf provides 查询成功后，还不能证明什么？

背面

不能证明包已安装或命令现在可执行。

安装后用 type 或 rpm -qf 验证。

正面

grep 没有输出时，为什么不能立即断言“无匹配”？

背面

输入可能不可读或上游失败；应查看退出状态与 stderr。

空输出只是现象。

正面

为什么 sort file > file 可能清空文件？

背面

Shell 在 sort 读取前就截断重定向目标。

写临时文件，验证后再替换。

正面

出现 command not found 时的调查顺序是什么？

背面

检查拼写 → type -a/PATH → 绝对路径 → dnf provides。

不要先猜包安装。

正面

创建 bzip2 压缩 tar 归档的选项组合是什么？

背面

tar -cjf <ARCHIVE.tar.bz2> <PATHS...>

-c 创建，-j bzip2，-f 指定文件。

正面

让 tar 从路径列表文件读取成员，使用哪个参数？

背面

-T <LIST_FILE>

路径中的换行等边界需与列表生成方式一致。

正面

查看 bzip2 tar 归档成员但不解包，命令骨架是什么？

背面

tar -tjf <ARCHIVE.tar.bz2>

用于验证成员内容。

正面

命令替换使用 […]；上一命令退出状态使用 […]。

背面

命令替换使用 $(command)；上一命令退出状态使用 $?。

两者分别处理输出文本和状态码。

正面

同时覆盖保存 stdout 与 stderr：command […] […]。

背面

同时覆盖保存 stdout 与 stderr：command >file 2>&1。

重定向按从左到右处理。

正面

已知命令查完整手册用 […]；按功能描述搜索命令用 […]。

背面

已知命令查完整手册用 man；按功能描述搜索命令用 apropos。

命令缺失时再用 dnf provides 反查包。
