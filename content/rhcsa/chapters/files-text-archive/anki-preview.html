共 33 条有效 Note；本页面不显示来源、稳定 ID 与标签。

正面

目录的 x 权限控制什么？

背面

允许穿越目录并访问其中已知名称。

文件可读但父目录缺少 x，路径访问仍失败。

正面

逐层查看路径中每个目录权限，推荐什么命令？

背面

namei -l <PATH>

比只看最终文件的 ls -l 更适合路径权限排错。

正面

硬链接的两个名称在 inode 上是什么关系？

背面

指向同一个 inode 和同一份数据。

stat 可比较 inode 与链接计数。

正面

硬链接为什么不能跨文件系统？

背面

inode 编号只在所属文件系统内有意义。

跨文件系统使用符号链接或复制。

正面

删除符号链接目标后，链接本身会怎样？

背面

链接仍存在，但成为指向不存在路径的悬空链接。

readlink 仍可显示其保存的路径。

正面

相对符号链接的目标从哪里解释？

背面

从符号链接所在目录解释。

不是从创建链接时的工作目录解释。

正面

sha256sum 相同能证明什么，不能证明什么？

背面

能证明字节内容相同；不能证明所有者、权限、时间或链接关系相同。

元数据另用 stat 验证。

正面

创建目录及缺失父目录的命令骨架是什么？

背面

mkdir -p <PATH>

已存在目录不会因此报错。

正面

一次复制文件、创建父目录并设置模式，推荐什么骨架？

背面

install -D -m <MODE> <SOURCE> <DEST>

题目还可能要求 -o 和 -g 设置身份。

正面

cp -a /src/. /dest/ 中的 /. 表达什么？

背面

复制源目录的全部内容到目标，包括隐藏成员。

它避免在目标下再创建一层 src。

正面

du -sh <DIR> 与 df -hT <PATH> 分别观察什么？

背面

du 看目录内容占用；df 看路径所属文件系统容量与使用率。

两者对象不同。

正面

find 的通用结构是什么？

背面

find <START> <TESTS> <ACTIONS>

起点、筛选条件和动作应分开阅读。

正面

用 find 只选择普通文件的条件是什么？

背面

-type f

目录用 -type d，符号链接用 -type l。

正面

find ... -size +10M 中的加号是什么语义？

背面

大于 10 个 MiB 单位。

无符号为按单位取整匹配，减号表示小于。

正面

find ... -mtime -7 的核心语义是什么？

背面

修改时间落在最近 7 个完整 24 小时计数范围内。

边界有取整，精确时间用 stat 抽查。

正面

为什么不推荐 for f in $(find ...) 处理路径？

背面

命令替换结果会按空白分词，破坏含空格或换行的文件名。

使用 -exec ... {} + 或 NUL 分隔。

正面

让 find 批量把路径作为独立参数传给命令，推荐什么动作？

背面

-exec <COMMAND> {} +

+ 批量调用，\; 通常逐个调用。

正面

find 与 xargs 之间安全传递任意文件名的组合是什么？

背面

find ... -print0 | xargs -0 ...

两端使用 NUL 作为记录分隔符。

正面

grep -E、-i、-n、-v 分别表示什么？

背面

扩展正则、忽略大小写、显示行号、反选。

递归搜索常用 -r。

正面

为什么 uniq 前通常先运行 sort？

背面

uniq 只识别相邻的重复行。

若需保留原顺序，应选择其他去重方法。

正面

验证文本筛选结果时，除了非空还应检查什么？

背面

结果数量、代表性匹配和应被排除的反例。

防止模式过窄或过宽。

正面

tar 的 -c、-t、-x、-f 分别是什么？

背面

创建、列出成员、提取、指定归档文件。

-f 后应跟归档路径。

正面

gzip、bzip2、xz 对应的 tar 短选项是什么？

背面

分别是 -z、-j、-J。

也可根据文件名和 file 验证格式。

正面

tar -C /srv -cJf out.tar.xz project 的 -C 有什么作用？

背面

创建成员前切换到 /srv，使归档成员从 project/ 开始。

它用于控制归档内路径前缀。

正面

查看 xz 压缩 tar 的成员但不解包，命令骨架是什么？

背面

tar -tJf <ARCHIVE.tar.xz>

成员存在不等于内容字节正确。

正面

rsync -a /src/ host:/dest/ 中源末尾斜线表示什么？

背面

同步 /src 的内容到目标，而不是在目标再创建 src 目录。

这是常见的目标层级差异来源。

正面

rsync 执行前预览差异使用哪个选项？

背面

-n 或 --dry-run。

与 -a 组合可预览归档模式同步。

正面

为什么 rsync --delete 不能作为默认同步选项？

背面

它会删除目标端源中不存在的额外文件，可能破坏数据。

只有题意明确要求镜像删除时使用。

正面

需要保留 find 结果相对目录结构时，GNU cp 的关键参数是什么？

背面

cp --parents

通常先切到查找起点，以免保留不需要的绝对前缀。

正面

归档并传输任务的最小验收组合是什么？

背面

源/目标路径集合、tar -t 成员、远端 stat、双端校验值。

传输命令退出 0 不能单独证明落点正确。

正面

硬链接共享[…]；符号链接保存[…]。

背面

硬链接共享同一个 inode；符号链接保存目标路径文本。

两者失效方式不同。

正面

安全路径批处理可用 find ... […]，NUL 管道使用 […] | xargs -0。

背面

安全路径批处理可用 find ... -exec command {} +，NUL 管道使用 -print0 | xargs -0。

避免空白分词。

正面

tar 压缩选项：gzip=[…]，bzip2=[…]，xz=[…]。

背面

tar 压缩选项：gzip=-z，bzip2=-j，xz=-J。

大写 J 是 xz。
