正面

image 与 container 的区别是什么？

背面

image 是只读模板，container 是其实例。

实例有独立运行状态。

正面

-p 8080:80 的方向是什么？

背面

宿主 8080 转发到容器 80。

宿主端口在前。

正面

bind mount 的 :Z 与 :z 区别是什么？

背面

:Z 私有重标记；:z 允许多容器共享。

按共享边界选择。

正面

查看全部容器含已退出实例用什么？

背面

podman ps -a

立即退出时先查。

正面

查看容器端口发布用什么？

背面

podman port <CONTAINER>

再用 ss 与 curl 验证。

正面

容器立即退出的证据入口是什么？

背面

podman ps -a、podman logs、podman inspect。

不反复创建。

正面

卷 permission denied 的调查层是什么？

背面

宿主 DAC、rootless UID 映射、SELinux 标签/AVC。

不 chmod 777 或禁用 SELinux。

正面

rootless 容器为什么要以目标用户运行 podman？

背面

容器存储、用户命名空间和 user units 都属于该用户。

root 是另一套状态。

正面

用户退出后仍运行 user service 的关键设置是什么？

背面

loginctl enable-linger <USER>

另需 user unit enabled。

正面

用户 unit 与系统 unit 的 systemctl 区别是什么？

背面

用户 unit 使用 systemctl --user 并在对应用户上下文。

管理器不同。

正面

容器 running 能否证明重启后运行？

背面

不能；还要验证 user unit enabled 与 linger。

当前/持久分开。

正面

完整容器验收骨架是什么？

背面

image → ps/logs/inspect → port/ss → volume/data → user unit/linger → HTTP。

分层取证。
