# 构建与发布

先运行 `uv run python tools/doctor.py`。正式构建使用：

```bash
uv run python tools/build.py rhcsa --profile reading --all-chapters
```

命令生成 33 个技术章、9 个分篇、含通用考试方法章的整书和 RHCSA APKG。单章试构建使用 `--chapter <slug>`。输出位于 `dist/rhcsa/reading/`；运行 `uv run python tools/pdf_qa.py dist/rhcsa/reading` 做结构检查并生成 QA Markdown。发布前还必须运行 lecture/Anki validation、pytest 和 repository audit。PDF 与 contact sheet 均为 ignored 产物，不纳入提交。
