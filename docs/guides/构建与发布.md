# 构建与发布

先运行 `uv run python tools/doctor.py`。正式构建使用：

```bash
uv run python tools/build.py rhcsa --profile reading --all-chapters
```

命令先生成并验收 33 个技术章，再将其与封面/目录前置页合并为整书，同时从 canonical YAML 构建 RHCSA APKG。单章试构建使用 `--chapter <slug>`。唯一正式输出位于 `releases/rhcsa-v5.1/`；运行 `uv run python tools/reading_release_qa.py` 做逐章、页数等式和单章/整书内容流一致性检查。发布前还必须运行 lecture/Anki validation、pytest 和 repository audit。PDF 与 contact sheet 均为 ignored 产物，不纳入提交。
